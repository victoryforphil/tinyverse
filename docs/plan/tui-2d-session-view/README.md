# TinyVerse 2D TUI Plan

This folder tracks the implementation plan for a new graphical, keyboard-first TUI surface in tinyverse.

Goal: add a `tinyverse tui` command that opens a navigable 2D session card view with an inspector sidebar and action system inspired by dark-factory's TUI interaction model.

Files:

- `00-context.md` - current architecture, constraints, and integration points.
- `01-dark-factory-port-map.md` - concrete source-to-target component mapping.
- `02-implementation-plan.plan.md` - staged build plan with acceptance gates.
- `03-implementation.prompt.md` - implementation handoff prompt.
- `TODO.md` - active execution checklist for this plan.
